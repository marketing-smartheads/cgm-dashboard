# Dentadmin AI Performance Dashboard — prototype

Een eerste Next.js prototype gebaseerd op het CGM-AI First model. De eerste focus is de Digital Analytics / performance dashboard-kant voor de Dentadmin pilot.

## Starten

```bash
npm install
npm run dev
```

Open daarna http://localhost:3000.

## Wat zit er nu in?

- Dashboard-shell met Dentadmin branding
- Overzicht met KPI's
- Website performance grafiek
- AI Insights-paneel
- Top pagina's
- SEO zoekwoorden
- Periode-selector
- Navigatie voor Website, SEO, Conversies en AI Insights
- Mockdata zodat het prototype direct zichtbaar werkt

## Volgende stap

De mockdata vervangen door een connectorlaag voor Google Analytics 4 en Google Search Console. Daarna kunnen AI-insights worden gegenereerd op basis van echte metrics.
